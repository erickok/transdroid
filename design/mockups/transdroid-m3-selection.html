Selection mode: long-press to select, act on one or many torrents

Long-press a row to start selecting. Tap rows to add or remove them. Tap a row without a selection to open its details. Try both devices.

Phone
Tablet (two-pane)

Entering and leaving

  • Long-press any row: it becomes selected (haptic tick) and the screen switches to selection mode.
  • While selecting, a tap adds or removes a row. Deselecting the last row, the close button or Back leave selection mode.
  • Without a selection, a tap opens details as today. Swipe gestures are gone, so the drawer swipe and the system Back gesture never collide with row actions.

Phone

  • Top bar becomes the selection bar: close, "N selected", select all (within the current filter).
  • The floating speed toolbar turns into the action toolbar at thumb height: Start, Pause, Check data, Label, Move, Remove, with the same filled icons as the details screen. The Add button hides.
  • Start/Pause are only enabled when some selected torrent can be started or paused.

Tablet

  • The selection bar spans both panes, as the normal tablet top bar does; its actions live in the summary pane, so they're not repeated in the bar.
  • The details pane shows a summary of the selection (count, size, speeds, labels, the selected torrents) with large action buttons, instead of one torrent's details.
  • Leaving selection mode brings back the details of the torrent that was open before.

Actions

  • Remove always asks first, with the count and the "Also delete downloaded data" option.
  • Label and Move open the existing sheets, titled "for N torrents". After an action, selection mode ends and a snackbar confirms, or reports partial failures ("Couldn't pause 2 of 5").
  • TalkBack users get Start/Pause/Remove as custom actions on each row.
